# Дизайн-система autismabroad.org

Единственный источник правды по токенам. Проверено против `index.html` на 2026-08-30.
Если нужного значения здесь нет — сначала добавь его сюда, потом используй в разметке.

## Характер

Одним предложением: **спокойный документ, а не лендинг** — как хорошо
свёрстанный справочник или письмо от человека, который уже прошёл этот путь.
Тепло даёт бумажный кремовый фон и приглушённый зелёный, а не градиенты и тени.

Чем это НЕ является: SaaS-лендингом, медицинским порталом, детским сайтом
с закруглёнными маскотами.

## Цвет

Палитра сознательно узкая: один доминирующий (teal), один акцент (coral),
остальное — тёплые нейтрали. Не расширять без необходимости.

| Токен | HEX | Роль |
|---|---|---|
| `ink` | `#2B2420` | Заголовки, основной текст на светлом |
| `body` | `#4A443D` | Текст статей |
| `muted` | `#6E655C` | Второстепенный текст, подписи |
| `teal-50` | `#F7F3ED` | Кремовый фон страницы |
| `teal-100` | `#E7EFEA` | Фон секций, подложка блоков |
| `teal-200` | `#D6E0D8` | Границы блоков |
| `teal-300` | `#A9BDB2` | Декоративные разделители — **только декор** |
| `teal-400..500` | `#7C998C` `#5F8072` | Промежуточные оттенки |
| `teal-700` | `#43625A` | Основной бренд-цвет, ссылки, `theme-color` |
| `teal-800` | `#33453D` | Тёмные подложки, футер |
| `coral-500` | `#D9724B` | Акцент — **см. предупреждение ниже** |
| `coral-600` | `#C15F39` | Hover акцента |

### Проверенные контрасты (WCAG, белый = `#FFFFFF`)

```
13.81  ink #2B2420 на кремовом #F7F3ED     ✅ AAA
 9.61  body #4A443D на белом                ✅ AAA
 6.70  teal-700 #43625A на белом            ✅ AA
 6.70  белый на teal-700                    ✅ AA
 5.16  muted #6E655C на кремовом            ✅ AA
 4.23  белый на coral-600 #C15F39           ❌ ниже 4.5
 3.25  белый на coral-500 #D9724B           ❌ ниже 4.5
 1.98  teal-300 #A9BDB2 на белом            ❌ ниже 3.0 для UI-границ
```

⚠️ **Открытый дефект.** Все главные CTA на сайте — белый текст на `bg-coral-500`
(`text-sm`/`17px` semibold). Это 3.25:1 при требуемых 4.5:1 → провал WCAG 1.4.3.
Hover-состояние `coral-600` (4.23:1) тоже не проходит.
Варианты исправления:
1. Затемнить акцент до **`#B25D3D`** (4.64:1) — минимальное изменение оттенка,
   визуально почти тот же коралловый;
2. Либо оставить `#D9724B`, но тогда текст на нём обязан быть крупным
   (≥ 24px, либо ≥ 18.66px bold) — тогда действует порог 3:1.
Первый вариант предпочтительнее: единый акцент во всех размерах.

`teal-300` не использовать как значимую границу интерактивного элемента —
для этого брать `teal-700` или `muted`.

## Типографика

Сейчас: **Inter** (вариативная, 100–900), self-hosted в `fonts/`, четыре
поддиапазона unicode — latin, latin-ext, cyrillic, cyrillic-ext.
Кириллица обязательна: сайт на et/ru/uk/en.

Inter — рабочий текстовый гротеск, но как единственный шрифт на всё он и есть
причина «сгенерированного» вида. Направление развития: **оставить Inter
на текст, добавить один дисплейный шрифт на заголовки**. Требования к кандидату:
вариативный, покрывает кириллицу, свободная лицензия, self-hostable.
Не подключать Google Fonts по сети — сломается приватность и `preconnect`-free
профиль сайта.

Шкала — через `clamp()`, не лестницей брейкпоинтов. Текущее фактическое
распределение: `text-sm` доминирует (64 использования). Для аудитории,
читающей длинные инструкции под стрессом, базовый размер тела статьи не должен
опускаться ниже 16px; `text-sm` — только для подписей и метаданных.

Тело статьи: `line-height: 1.75`, элементы списка `1.65` — уже задано, сохранить.
Длина строки: 60–75 знаков. Заголовкам — `text-wrap: balance`, абзацам — `pretty`.

## Форма и пространство

Радиусы: `rounded-2xl` (34 использования), `rounded-full` (28), `rounded-3xl` (11),
плюс единичный `rounded-4xl` (2rem).
Это слишком много уровней при слишком однородном применении.
**Правило:** три радиуса максимум — мелкий (кнопки, бейджи), крупный (карточки,
секции), полный (аватары, пилюли). Один уровень вложенности = один радиус.

Тени: сейчас почти не используются (`shadow-lg` один раз) — это правильно,
так и держать. Разделение блоков делается фоном или границей, не тенью.
Не добавлять `shadow` к элементам, у которых уже есть фон и граница.

Спейсинг: разрывы между уровнями иерархии должны отличаться заметно,
а не на один шаг шкалы. Внутри карточки — тесно, между секциями — просторно.

## Движение

Что есть: `transition` на карточках с `transform` на hover,
корректно снятое под `@media (prefers-reduced-motion: reduce)`.

Что нужно доделать:
- `html { scroll-behavior: smooth }` задан безусловно — обернуть в
  `@media (prefers-reduced-motion: no-preference)`. Для аудитории с
  вестибулярной и сенсорной чувствительностью это не косметика.
- Бюджет: 3–5 микровзаимодействий на страницу, 150–250 мс, `ease-out`
  на появление.

## Открытые дефекты (по состоянию на 2026-08-30)

1. **Нет ни одного стиля фокуса** — `focus-visible`/`focus:` не встречается
   в `index.html` ни разу. Навигация с клавиатуры невидима. Провал WCAG 2.4.7.
   Это самый серьёзный пункт списка.
2. **Контраст CTA** — белый на `coral-500`, 3.25:1. Провал WCAG 1.4.3. См. выше.
3. **Tailwind подключён через `cdn.tailwindcss.com`** — рантайм-компилятор CSS
   в браузере: внешний запрос (мимо self-hosted-политики сайта), блокирующий
   скрипт в `<head>` и риск по LCP/CLS. В прод нужен собранный статический CSS.
4. **`scroll-behavior: smooth` без учёта `prefers-reduced-motion`.**
5. **Однородные радиусы** — `rounded-2xl` на всём подряд, признак дефолта.
6. **Единственный шрифт на все роли** — нет типографической иерархии
   уровня «дисплей vs текст».

Пункты 1 и 2 — нарушения доступности при действующем European Accessibility Act,
их стоит закрыть раньше любых визуальных улучшений.
